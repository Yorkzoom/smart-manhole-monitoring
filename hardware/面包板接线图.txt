【面包板孔位规则】
  - 10行: a,b,c,d,e (上半区) | 中间沟槽 | f,g,h,i,j (下半区)
  - 64列: 0-63 (从左到右数)
  - 同一列 a-e 互通，同一列 f-j 互通，上下半区被沟槽隔断

【第一步】插入 ESP32 Dev Module (USB口朝上，斜排针朝下)

【第二步】电源干线 (先接这4根，所有传感器的电从这里引)
  ╔══════╤══════╤══════════╤══════════════════════════════╗
  ║ 颜色 │ 从哪 │ 到哪     │ 作用                         ║
  ╠══════╪══════╪══════════╪══════════════════════════════╣
  ║ 🔴  │ a5   │ 上电源轨[+] │ ESP32 3.3V → 给所有3.3V传感器  ║
  ║ ⚫  │ a18  │ 上电源轨[-] │ ESP32 GND → 给上半区地线     ║
  ║ 🔴  │ VIN* │ 下电源轨[+] │ ESP32 5V → 给MQ系列传感器    ║
  ║ ⚫  │ f29  │ 下电源轨[-] │ ESP32 GND → 给下半区地线     ║
  ╚══════╧══════╧══════════╧══════════════════════════════╝
  * VIN引脚：USB供电时输出5V，在右排最上方，标有"VIN"

🔴 电源隔离检查（最重要！）:
  ☐ MQ-2/4/135 的 VCC 有没有误接上电源轨 [+] (3.3V)？ → 如有，拔掉改下电源轨
  ☐ 上电源轨 [+] 上是否只有 3.3V 设备？ → 确认没有 5V 设备
  ☐ 下电源轨 [+] 上是否只有 MQ 系列传感器？ → 确认没有 3.3V 设备

🟡 引脚连通性检查:
  ☐ GPIO22(列f25) 同时接了 MPU6050 SCL 和 BH1750 SCL（并联没问题）
  ☐ GPIO21(列f28) 同时接了 MPU6050 SDA 和 BH1750 SDA（并联没问题）
  ☐ GPIO34(列a9) 只接了 MQ-2 AO
  ☐ GPIO35(列a10) 只接了 MQ-4 AO
  ☐ GPIO32(列a11) 只接了 MQ-135 AO
  ☐ GPIO15(列f38) 只接了 DHT11 DATA

🟢 物理检查:
  ☐ 所有杜邦线插到底，没有金属露在外面
  ☐ 相邻排针间没有短接（杜邦线金属夹没有碰到相邻的针脚）
  ☐ ESP32 插紧在面包板上，不会晃动
  ☐ 所有传感器插紧，引脚没有弯曲
  ☐ 面包板背面没有金属物体导致短路
